A start-from-zero playbook for one person who wants to build websites with AI and sell them to local businesses. It assumes you have never built a website, never priced a job, and never run a company. It teaches all three at once.

## How it is organised

The playbook is built around Michael Gerber's idea from *The E-Myth* that every small business owner is really three people at once, and that those three fight each other. There is one section for each.

- **The Technician** does the work — builds the site.
- **The Manager** makes the work repeatable — prices it, schedules it, invoices it.
- **The Entrepreneur** decides what the business is — who it serves and what it charges.

Most owners are roughly 70% Technician, and that imbalance is why most small businesses stay small. The playbook gives each role its own part.

## Two things that make it unusual

**Every number is sourced.** The market figures come from named 2025 and 2026 industry surveys, not from guesswork. Where sources conflict, the playbook says so rather than picking the convenient one.

**It is written to a measured reading level.** Every chapter is held to a Gunning Fog index between 8.5 and 9.5, roughly a high-school freshman. That is checked with a script before anything ships, and the score is printed on each chapter.

## Running it locally

Every page is a single self-contained HTML file. There is no build step, no database, and no server code.

```
git clone https://github.com/Cloudenvy7/automated-website-business.git
cd automated-website-business
open index.html
```

Or upload the folder to any static host.
