# Instructions for contributors and AI

This repository is the public playbook *The Automated Website Business* by Black Fox Studios. It is served by GitHub Pages straight from the repository root: every chapter is a self-contained HTML file (`index.html`, `mod-*.html`), and `.nojekyll` must stay. Add files; do not move or rename the existing pages.

## Sources

Source documents behind the playbook live in `sources/`, one file per document, and are listed in the [source register](docs/SOURCES.md). Each file opens with a header saying where the original lives, its dates, when it was copied and why it is here.

- The original (usually a Google Doc in the Black Fox Studios shared drive) is the record. The file here is a mirror of it. Update the original first, then copy it here and change the header date.
- Read the source register before answering questions about how a Black Fox Studios site is built, and read the source itself, not a summary of it.
- The legal, privacy and licensing items for client sites are in the [Website Build Standard and Checklist](sources/build-standard/website-build-standard-and-checklist.md). Module 11's twenty-point list is the quick quality pass; the build standard is the full launch gate.

## Public repository

Anyone can read this repository. Never add client names, personal details, private Drive or Docs sharing links, account or ID numbers, passwords or keys. A Drive document id on its own is fine. If a source contains anything private, leave it out of the mirror and say so in its header.

## Chapters

Chapters are written to a Gunning Fog index between 8.5 and 9.5, and each prints its score. If you change a chapter's body text, re-run the score before shipping. Keep the author's chapters as written; do not rewrite them.
